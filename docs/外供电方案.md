# 外供电方案（不折腾电池）

> 起因：板上稳压是 **AMS1117**，静态电流 ~5 mA。
> 这个数字比 ESP32-S3 深度睡眠（8.14 µA）**大 600 倍**，
> 电池方案省下来的电全被 LDO 吃掉 —— 所以**放弃电池，走常供电**。

---

## 一、结论

**这块板本来就是长通电设计，直接供 5V 就行，功耗不用管。**

| 项 | 数值 | 含义 |
|---|---|---|
| ESP32-S3 活跃 | 23.88 mA（官方） | 常态 |
| EPD 刷新峰值 | ~15 mA | 每次 15~20 秒 |
| AMS1117 静态 | ~5 mA | 常驻 |
| **5V 侧总电流** | **30~50 mA**，峰值 120 mA | — |

一年耗电 ≈ `0.04A × 5V × 8760h ≈ 1.75 kWh`，电费几块钱。
**所以别优化功耗了，怎么方便怎么来。**

---

## 二、三种接法，按推荐度排序

### 方案 A：USB 充电头（零改动，先用这个）

```
墙上插座 → 5V/1A USB 充电头 → Type-C 线 → 板子
```

| 项 | 说明 |
|---|---|
| 成本 | ¥10~20 |
| 改动 | **零** |
| 风险 | 无 |
| 缺点 | 线材外露，不够"做成产品" |

**先用这个把东西摆起来**。确认日常使用没问题，再考虑下面的方案。

---

### 方案 B：焊 5V + GND 邮票孔（推荐做成品）

**板上有独立的 `5V`（丝印 `sv`）和 `GND` 邮票孔**，和 `3V3` 在同一组。

```
外部 5V 电源 ──┬── 焊到板子 `5V` 邮票孔
               └── 焊到板子 `GND` 邮票孔
```

| 项 | 说明 |
|---|---|
| 成本 | ¥15~30（+ 电源） |
| 改动 | 焊 2 根线 |
| 难度 | **低**——邮票孔间距大（2.0mm 左右），普通烙铁就能焊 |
| 风险 | 低，但要**防倒灌**（见 §三） |

> **为什么比焊 Type-C 好**：Type-C 母座是贴片件，引脚在座子底下、
> 间距 0.3mm，手焊基本焊不到；邮票孔是通孔焊盘，好焊得多。

---

### 方案 C：焊 Type-C 的 VBUS/GND（不推荐）

如果坚持要从 Type-C 并线：

| 引脚 | 位置 | 说明 |
|---|---|---|
| VBUS | A4 / B4 / A9 / B9 | 5V 正极（4 个脚并联） |
| GND | A1 / B1 / A12 / B12 | 地 |

**实际情况**：

- 板上 Type-C 是**贴片母座**，焊盘在座子底下，要拆座子才能焊
- 或者刮开 PCB 上的 VBUS 走线覆铜，飞线出来 —— 需要显微镜级别的操作
- **性价比极低**，除非你本来就要拆掉 Type-C 座

**结论：有 `5V` 邮票孔就不用碰 Type-C。**

---

## 三、⚠️ 防倒灌（方案 B/C 必读）

外部 5V 和 USB 5V 是**同一个网络**（都连到 AMS1117 输入）。
两个源并联会互相灌电流 —— USB 口可能反送电到外部电源，反之亦然。

**三种处理，按推荐度：**

### 1. 加个拨动开关（最简单）

```
外部 5V ──[开关]── 板子 5V 邮票孔
```

开关断开时插 USB，闭合时用外部电源。**二选一，永不冲突。**

- 开关型号：SS-12D00（微型拨动，¥1）
- 便宜、可靠、零风险

### 2. 串肖特基二极管（想同时供电时）

```
外部 5V ──|>|── 板子 5V     （SS34 / 1N5819）
```

- 正向压降 0.3~0.5V → 板子实际拿到 4.5~4.7V
- AMS1117 在 120mA 下压差需求约 0.4~0.5V，`4.5 - 3.3 = 1.2V` **余量够用**
- 好处：插 USB 时外部电源自动让路，不用手动切

> 用二极管后板子端电压会降到 4.5V 左右，虽然够用但余量不大。
> **电源选 5.2~5.5V 更稳**；或者直接用方案 1 的开关（无压降）。

### 3. 什么都不做（只在确定不会同时插时）

如果这块板以后就固定用外部电源、USB 线只在烧录时插 —— **烧录前拔掉外部电源**即可。

---

## 四、电源选型

| 参数 | 要求 | 说明 |
|---|---|---|
| 电压 | 5V ±5% | 4.75~5.25V |
| 电流 | **≥1A** | 峰值 120mA，留余量 |
| 纹波 | < 100 mV | 纹波大会导致 BLE 断连 |
| 接口 | USB-A / DC 5.5×2.1 / 端子 | 看外壳 |

**别用劣质充电头**：ESP32 对电源敏感，BLE 发射瞬间的电流突变会让劣质电源
掉压到 4V 以下 → 板子重启 → 表现为「设备时不时消失」。

**推荐**：
- 手机充电头（5V/2A）—— 手头有就用
- 或 5V/1A 电源适配器（¥10~15）
- 有条件的选带 EMC 滤波的

---

## 五、线材与走线

| 项 | 建议 |
|---|---|
| 线径 | **AWG24 以上**（0.5mm²），峰值 120mA 够用 |
| 长度 | 越短越好，>1m 建议加 100µF 电容在板子端 |
| 接头 | 焊死最可靠；要可拆就用 XH2.54 端子 |

**加个去耦电容**（可选但推荐）：

```
外部 5V ──┬── 板子 5V
          │
        ──┴── 100µF 电解 + 100nF 陶瓷
          │
         GND
```

装在板子附近，能明显改善 BLE 稳定性。

## 六、外壳开孔

| 项 | 尺寸 |
|---|---|
| Type-C 孔（保留充电/烧录） | 9 × 3.5 mm |
| DC 母座孔（若用 DC 头） | Ø 8 mm |
| 电源线出线孔 | Ø 4 mm + 橡胶护线圈 |
| 开关孔 | 3 × 6 mm（SS-12D00） |

**建议保留 Type-C 外露**：烧录固件时要插 USB，别封死。

## 七、如果想做得更"产品化"

### 选项 1：DC 母座

```
DC 5V 电源 → DC-005 母座（焊在板子 GND/5V）→ 板子
```

- 母座 ¥1，电源 ¥10
- 插拔可靠，比 USB 稳
- 缺点：要占一点空间

### 选项 2：USB 母座转接小板

买「USB-A 母座转 2P 排针」小板（¥3），焊 5V/GND 引出，

```
USB 充电头 → USB 线 → 转接板 → 排针 → 板子 5V/GND
```

- 免焊 Type-C，用现成 USB 线
- 适合不想焊板子的人

### 选项 3：直接嵌一个 USB 充电头

如果外壳够大，把 5V/1A 的裸板电源模块（¥8）塞进去，
外壳上只留一个 8 字电源线孔。**最像成品**。

---

## 八、推荐路径

```
第 1 步：USB 充电头 + 现有线          ← 今天就能摆起来
第 2 步（可选）：焊 5V/GND + 拨动开关  ← 想做整洁了再改
第 3 步（可选）：装进外壳，留 Type-C 外露
```

**不要一开始就焊**。先用充电头确认整套东西稳定运行几天，
（尤其是 BLE 同步、屏幕刷新都正常），再动烙铁。

## 九、顺便：既然常供电，可以把这些打开

不用考虑省电之后，有些之前不敢开的能开了：

| 项 | 说明 |
|---|---|
| **广播间隔缩短** | 从 1000ms 拉回默认 ~160ms，主机连接更快 |
| 连接间隔优化 | `setMinPreferred(0x06)` 已设，手机端更跟手 |
| 刷新更勤 | 天气变化就刷，不用攒着 |
| 加个状态灯 | 刷新时亮一下，方便确认在干活 |

**注意**：常供电后 EPD 的寿命成为主要约束，不是电。
按一天刷 4 次算，一年 1460 次 —— EPD 典型寿命在**百万次刷新**量级，
即使用十年也才 1.5 万次，**远没到上限，随便刷不用省**。

> 相比刷新次数，更该注意的是**工作温度**（这块屏标称 0~40°C）
> 和**避免长期暴晒**（E Ink 对紫外线敏感）。
